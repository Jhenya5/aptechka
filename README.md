# Аптечка

Мини-приложение для учёта домашних лекарств: расписание приёмов, остатки по упаковкам разной дозировки, еженедельное заполнение таблетницы и список того, что пора заказать.

**Открыть:** https://jhenya5.github.io/aptechka/

- Доза задаётся в мг по назначению, а приложение само считает, сколько таблеток выпить из тех, что есть дома (½, 2 шт. и т. п.).
- Режим таблетницы: в день заполнения показывает, что положить в каждую ячейку, и списывает запас на неделю.
- Экспорт и импорт: весь список с запасами, памяткой и журналом переносится текстом или файлом между устройствами и версиями.
- Устанавливается как приложение (PWA) на компьютер и телефон, работает без интернета.
- Синхронизация между устройствами через файл `data.json` в вашем приватном репозитории (ключ доступа GitHub вводится на каждом устройстве и хранится только в его браузере). Без синхронизации данные остаются только на устройстве.

Статический сайт без сборки: `index.html`, `manifest.webmanifest`, `sw.js` и значки.
